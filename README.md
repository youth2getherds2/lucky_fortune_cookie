# 오늘의 운세 · 포춘쿠키 🥠

대상 대학생 봉사단 9기 X 형제식당

포춘쿠키를 눌러 오늘의 운세와 행운의 음식을 확인하는 웹페이지입니다.
설치할 것도, 서버도 필요 없습니다. HTML 파일 하나로 동작합니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 사이트 본체. 이 파일 하나에 디자인·애니메이션·운세 내용이 모두 들어 있습니다. |
| `.nojekyll` | GitHub Pages가 파일을 있는 그대로 올리도록 하는 설정 파일 (내용은 비어 있음) |
| `README.md` | 이 설명 파일 |

## 배포 방법 (GitHub Pages)

1. GitHub에 새 저장소(Repository)를 만듭니다. **Public**으로 설정합니다.
2. 이 폴더의 파일 3개를 저장소에 업로드합니다.
3. 저장소 상단 **Settings → Pages** 로 이동합니다.
4. Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 지정하고 Save를 누릅니다.
5. 1~2분 뒤 페이지 상단에 주소가 나타납니다.
   `https://<내아이디>.github.io/<저장소이름>/`
6. 이 주소를 공유하면 누구나 접속할 수 있습니다.

## 내용 수정하기

### 운세 문구 바꾸기

`index.html` 아래쪽 `<script>` 안의 `fortunes` 목록을 수정합니다.
한 줄이 화면의 한 줄로 표시됩니다.

```js
const fortunes = [
  ['오늘 배운 것이', '미래의 자산이 됩니다. 📚'],
  ['작은 노력이 모여', '큰 성과를 만듭니다.'],
];
```

### 행운의 음식 바꾸기

바로 아래 `luckyFoods` 목록에서 메뉴를 추가하거나 지우면 됩니다.

```js
const luckyFoods = ['계란찜', '매운갈비찜', '된장찌개'];
```

### 안내 문구 바꾸기

`LEDE_BEFORE`(쿠키 열기 전), `LEDE_AFTER`(쿠키 열고 난 뒤) 값을 고치면 됩니다.

수정한 뒤 저장소에 다시 올리면 1~2분 안에 사이트에 반영됩니다.
